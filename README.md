# Binance Futures Trading Bot (Testnet)

A simplified **Python-based trading bot** built for the **Binance Futures Testnet (USDT-M)** as part of a hiring assignment.  
The bot allows users to place Market, Limit, and Stop-Limit orders via a **Command Line Interface (CLI)** using the official Binance Futures API.

---

## 🚀 Features

- ✅ Market Orders (BUY / SELL)
- ✅ Limit Orders (BUY / SELL)
- ✅ Stop-Limit Orders (Bonus)
- ✅ Binance Futures **Testnet (USDT-M)** support
- ✅ Command-Line Interface (CLI)
- ✅ Input validation
- ✅ Logging of API requests, responses, and errors
- ✅ Clean, reusable code structure

---

## 🛠️ Tech Stack

- **Language:** Python 3.x  
- **Library:** python-binance  
- **API:** Binance Futures Testnet (USDT-M)  
- **Logging:** Python `logging` module
